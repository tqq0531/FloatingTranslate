浮译 Windows 0.1.1 · 离线测试包
适用 Windows 10 / 11 x64 的 64 位桌面软件。

【开始使用】
1. 完整解压到固定目录，建议 C:\Apps\FloatingTranslate。
2. 双击“启用浮译.cmd”，批准管理员提示，等待离线自检并注册完成。
3. 按 Win + 空格，选择“浮译”。
4. 输入 nihao，按空格确认；浮窗显示英文。第一次翻译会稍慢。

程序、拼音词库、中译英模型和必要运行库全部在包内。
不用另下语言包，不用安装 Python、Java、.NET 或开发工具。
Windows 输入法首次使用需要注册，因此不能做到完全零操作。
若缺少微软运行库，启用程序会自动运行包内的官方安装程序。

【主要操作】
轻按 Shift：切换中文拼音 / English 直接输入。
空格、1–5 或鼠标：选词。方向键 / PageUp / PageDown：切换候选。
分段输入“我 / 今天 / 去北京”：按当前整句更新翻译。
鼠标拖选英文后按 Ctrl+C 或右键复制；复制按钮可复制整句。
“浮译设置.cmd”可以设置默认输出语言、浮窗上下位置及隐私模式。
默认英文：先选中文候选，再按空格或回车提交就绪译文。
Tab：输入另一种语言。无法安全替换已确认的前文时请复制英文。

【建议测试】
可以关闭网络后试用。也可运行“检查离线组件.cmd”。
请试试 nihao、nh、zhogn、nihoa，以及分段输入整句、中英切换和复制。
如有问题，请提供 Windows 版本、软件名称、操作步骤和不含私人信息的截图。
该包仍需 Windows 实机验收，不是已保证所有软件兼容的正式版。
不支持 32 位应用或 Windows ARM64 原生应用；高 DPI/多显示器待实机验证。

【隐私】
翻译在本机执行，不调用云翻译，不保存输入历史，不读取剪贴板。
只有你明确复制英文时才向系统剪贴板写入；系统剪贴板同步由 Windows 决定。
密码框会尽量跳过，但自定义密码框无法可靠识别。
输入密码、验证码、密钥前，请切换系统键盘。

【停用或删除】
启用后请保留当前目录，不要移动、重命名或直接删除。
先切换其他输入法，保存工作，再双击“停用浮译.cmd”。
关闭使用过浮译的软件，文件不再占用后再删除文件夹。
若仍占用，可正常注销 Windows 后删除。不要强制结束有未保存内容的软件。
